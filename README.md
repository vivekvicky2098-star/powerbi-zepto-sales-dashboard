# Zepto Sales Dashboard (Power BI)

## Project Overview
This is a one-page Power BI dashboard created to analyze sales performance, customer behavior, and product trends.

## Tools Used
- Power BI
- DAX
- Excel

## Key KPIs
- Total Sales
- Total Gross Income
- Total Quantity
- Average Rating

## Visuals
- Sales Trend Over Time
- Sales by City
- Sales by Product Line
- Sales by Customer Type
- Sales vs Average Rating (Scatter)
